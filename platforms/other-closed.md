# Other closed platforms

## Panasonic (My Home Screen, 2014–2023)
Closed Firefox OS descendant: no ADB, no developer mode. Settings › Network / Setup: decline the viewing
data and "Personalized" options in the privacy menus; set the TV to start on the last input.
DNS: `dns/panasonic.txt`. 2024+ Panasonic sets run Fire OS → `fire-os.md`.
Panasonic Android/Google TV models → `android-tv.md`.

## Philips (Saphi)
Cheaper Philips sets. Only the JointSpace API (port 1925: power, Ambilight, keys, inputs). Settings: turn
off usage data/ads in the privacy menu; DNS: `dns/philips.txt`. Philips Android/Google TV sets are fully
covered by `android-tv.md`.

## The option that always works
Never connect the TV to a network and drive it from a box the owner controls (Apple TV, a debloated
Google TV Streamer or Shield, a Kodi box). No firmware fights, nothing to re-apply after an update.
